# Features

## Customer automation

Webhook gating, Redis debounce, state/memory, pricing tools, media analysis, voice transcription, order collection and confirmation, human takeover, duplicate suppression, inactivity handling and customer-file bundling.

## Dashboard navigation

- Overview: period-based counts, resolution activity and observed workload.
- Conversations: resolved records, ID/name/phone search, label/agent filters, pagination and current-page CSV.
- Agent analytics: actual reply participation, current ownership, observed load, availability and evaluation-dependent quality.
- Review queue: admin feedback and evaluation-job status.
- AI improvement: evaluation-dependent categories, weekly trends and descriptive before/after bot-change comparisons.
- Learning examples: drafts, activation, archival, version history and restore.
- Evaluation rules: draft/active/archive lifecycle and history.
- Settings: connection status, monitoring coverage, audit trail and verified encrypted backups.

## Conversation review

Assessment, responsibility evidence, waiting/workload observations, separate AI issues, transcript with original attachments, saved Gemini media evidence and scoped admin feedback.

English/Arabic RTL; Cairo timestamps; private read-only Chatwoot linkage; 30-minute refresh/cache; immediate dashboard-owned admin changes. First uncached requests can still query Chatwoot.
